# T-308 — Fan-out delivery and replay on reconnect

The heart of the system: deliver a new message to every live listener for the recipient, and replay everything still pending whenever a listener says hello.

## Acceptance criteria

- [ ] A new message is pushed to every active socket for the recipient agent and project, and each attempt is recorded.
- [ ] On hello, all pending messages replay in chronological order followed by a ready frame carrying the pending count.
- [ ] A message sent while the recipient is offline is delivered on the next hello.
- [ ] A listener that dies before acknowledging receives the message again on restart.
- [ ] Delivery failure to one socket never prevents delivery to another.
- [ ] Integration tests cover fan-out to two sessions, offline delivery, and crash-before-acknowledge replay.
