# T-510 — Self-hosting and upgrade documentation

The operator-facing manual. Since hosting is the user choice in an open-source project, this determines whether anyone can actually run it.

## Acceptance criteria

- [ ] Self-hosting covers requirements, the GitHub application setup, every environment variable, first run, and backups.
- [ ] The upgrade guide gives the exact backup, upgrade, verify, and rollback sequence.
- [ ] The compatibility promise and its limits are stated plainly, including what a major version may break.
- [ ] Database major-version upgrades are addressed by pointing at the correct tooling.
- [ ] A person who has never seen the repository can follow it end to end.
