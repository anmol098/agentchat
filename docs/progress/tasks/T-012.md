# T-012 — Extract the repeated CI setup into a composite action

Three jobs each repeat the same setup: check out, install pnpm, install Node, restore the store cache, install dependencies. Duplication in a workflow is quietly expensive, because the copies drift. A version bumped in two of three places produces a failure that looks like a code problem and is not.

## Acceptance criteria

- [ ] A composite action holds the shared setup, and every job uses it.
- [ ] Job names and behaviour are unchanged, so branch protection needs no edit.
- [ ] Cache behaviour is preserved; show a run where the store cache is hit.
- [ ] Node version is a single input with one default, so raising it is a one-line change.

Identified by T-004, which could not create it because `.github/actions/` was outside that task's owned paths.
