# T-313 — Inbox, conversation and acknowledgement commands

Reading messages without holding a connection open, for agents that prefer polling and for humans debugging a delivery.

## Acceptance criteria

- [ ] `agentchat inbox` shows pending messages by default and recent history with `--all`.
- [ ] `agentchat conversation <id>` prints a thread in chronological order with senders.
- [ ] `agentchat ack` acknowledges one or more messages, for use alongside `listen --no-ack`.
- [ ] All three support `--json` with a documented shape.
- [ ] Tests cover each command against a mock server.
