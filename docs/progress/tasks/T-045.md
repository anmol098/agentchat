# T-045 — Check a branch's changed files against its task's declared paths

The board's whole parallelism guarantee rests on declared paths being disjoint. `check` proves they do not overlap. Nothing proves they are **complete**, because the board never sees a worktree's diff.

T-314 is the case that made this concrete. It declared `server/test/integration` — a directory that does not exist, since integration tests live in `server/tests/*.integration.test.ts` — and `tests/e2e`. While running, it also modified `server/src/app.ts` and `vitest.config.ts`. Neither was declared, `app.ts` is owned by T-041, and the board reported no collision, because a path nobody declares collides with nothing.

The failure is silent in the direction that matters. Two agents can be editing the same file for an hour with every board command reporting success.

## Acceptance criteria

- [ ] A `scope <ID>` command that lists the files a task's branch has changed and fails on anything outside its declared paths.
- [ ] It sees uncommitted work too. An agent's undeclared edit should be caught while it is still in the worktree, not only after it commits.
- [ ] A declared source file covers its sibling test files, or every task fails the check on its own tests and the check gets ignored.
- [ ] A task may always touch its own task file and `BOARD.md`. Those are how it reports progress.
- [ ] `docs/protocol.md` is allowed, because §7.6 requires a wire change to update it in the same pull request. Flagging every such change would train reviewers to ignore the output.
- [ ] The failure message says what to do: either revert the file, or widen the task's `paths` deliberately and say why in the Log.
- [ ] `docs/SUBAGENT-PROTOCOL.md` §5 and §10 tell agents and the orchestrator when to run it.

## Notes

Recorded first in `docs/progress/NEEDS-ATTENTION.md` §2 as a judgement call for the maintainer. It is being implemented rather than deferred because the blind spot is already costing scheduling decisions: T-041 was held rather than started, on evidence the board could not produce.

This does not replace declared paths, and it is not a sandbox. An agent can still write anywhere; the check only makes it visible.
