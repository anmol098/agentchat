# T-302 — Session service, registration and stale sweeping

Session lifecycle: registration when a listener starts, heartbeat tracking, automatic transition to stale, and explicit teardown.

## Acceptance criteria

- [ ] Session registration records agent, project, machine, runtime, and working directory, and upserts the machine.
- [ ] Runtime is a required field taken from the caller and is never inferred.
- [ ] A session with no heartbeat for sixty seconds becomes stale; a stale session older than a day becomes ended.
- [ ] The sweeper is idempotent and safe to run repeatedly.
- [ ] A caller can only register or end a session for an agent it owns.
- [ ] Integration tests cover the full transition sequence.
