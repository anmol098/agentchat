# T-204 — File-backed credential store

Persists tokens on disk with correct permissions, implementing the interface the client package defines.

## Acceptance criteria

- [ ] Credentials are written to the documented config path with mode 0600, and the parent directory with 0700.
- [ ] Writes are atomic so an interrupted write cannot corrupt the file.
- [ ] A corrupt or unreadable file produces a clear message telling the user to log in again, never a stack trace.
- [ ] Tokens never appear in log output.
- [ ] Tests cover permissions, atomicity, and corruption recovery.

## Notes

Plan section 6.1, PRD section 29. OS keychain storage is deliberately deferred to v0.2.
