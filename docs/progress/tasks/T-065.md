# T-065 — The CLI reference still describes the agent-name grammar T-060 replaced

Under `agent create`, `docs/cli.md` says:

> The name must be 1 to 32 lowercase letters, digits and hyphens, starting with a letter or digit, and unique among your live agents.

That was true before T-060 and is not now. The grammar is `^[a-z0-9](?:[a-z0-9]|-(?=[a-z0-9])){0,31}$`: hyphens must be **single** and may not **end** the name. So `my-agent-` and `my--agent` read as legal in the reference and are refused by the schema and by the database.

The schema already words it correctly, and the reference should say the same thing rather than a paraphrase:

> Expected an agent name of 1 to 32 lowercase letters and digits joined by single hyphens, starting and ending with a letter or digit.

## What is *not* stale, checked before filing

The `protocolVersion` in the three `agentchat version` transcripts. It was 3, then T-062 took it to 4, then the release took it to 5, and all three now read 5, matching the constant. Only the grammar sentence is wrong.
