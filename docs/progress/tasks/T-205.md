# T-205 — Project and agent context resolution

How every command works out which project and which agent it is acting for, walking up from the working directory and falling back through flags, environment, and user configuration.

## Acceptance criteria

- [ ] Project resolution follows the documented order and walks up to the filesystem root looking for the repository configuration.
- [ ] Agent resolution follows the documented order, including the single-agent-in-project shortcut.
- [ ] Failures exit 4 with a message naming the specific command that fixes the situation.
- [ ] Repository configuration contains no secrets and is safe to commit.
- [ ] Tests cover nested directories, an explicit flag override, environment variables, and both failure modes.

## Notes

Plan §6.1, PRD §14, decision D12. Agent choice is personal so it lives in user config, not the shared repository file.
