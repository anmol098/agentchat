# T-203 — CLI skeleton with output modes and exit codes

The command framework: argument parsing, the human and JSON renderers, the exit-code contract, and the stdout and stderr discipline every command inherits.

## Acceptance criteria

- [ ] The `agentchat` binary is registered and runs from a built package.
- [ ] Every command supports `--json`, and JSON mode emits nothing but valid JSON on stdout.
- [ ] Exit codes follow the contract: 0 success, 1 generic, 2 usage, 3 authentication required, 4 missing context.
- [ ] Operational output goes to stderr; only results go to stdout.
- [ ] Errors render with the stable code and an actionable next step.
- [ ] Tests spawn the built binary and assert stream separation and exit codes.
