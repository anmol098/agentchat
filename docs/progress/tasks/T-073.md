# T-073 — Release 0.2.1, so a deployed server stops reporting live listeners as offline

The presence fix (T-069) is on `main` and in no release. Every 0.2.0 server marks a listener stale a minute after it connects, so `agentchat agents` reports online agents as offline while messages keep arriving. The maintainer's own deployment shows it. A patch release carries the fix; nothing in it changes the wire protocol or the schema, so the protocol version stays at 5, the minimum client stays at 0.1.0, and the upgrade is a container swap with no migration.

## Acceptance criteria

- [ ] Every pinned version reads 0.2.1: the five manifests, `CLI_VERSION`, `SERVER_VERSION`, the example environment file, and the documents that name the current release.
- [ ] The release rehearsed from the task branch with a dry-run dispatch before the tag exists, and every job passed.
- [ ] `v0.2.1` tagged on `main` after the bump merges; the release workflow publishes the image, the three packages, and the GitHub Release with upgrade notes.
- [ ] The upgrade workflow on `main` stays green after the release.

## Notes

The 0.1.0 libraries on npm are unaffected; they are still to be deprecated by the maintainer.
