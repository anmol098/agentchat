# T-109 — Agent routes including soft delete

Agent lifecycle: create, list, rename, add to and remove from projects, and soft delete without breaking message history.

## Acceptance criteria

- [ ] Endpoints from Plan section 3 are implemented, and agent names are validated against the documented pattern.
- [ ] Soft delete sets the timestamp, ends the agent sessions, removes project participation, and leaves historical messages intact.
- [ ] A deleted agent cannot be addressed as a recipient and is absent from discovery.
- [ ] The freed name can be reused by the same user.
- [ ] Integration tests cover the full lifecycle including deletion followed by reuse.
