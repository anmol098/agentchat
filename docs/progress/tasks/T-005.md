# T-005 — Protocol package skeleton with IDs and error codes

The shared vocabulary every other package imports: prefixed identifiers, the stable error-code enum, the error envelope, and the protocol version constant.

## Acceptance criteria

- [ ] UUIDv7 generation and validation for each prefix: `usr_`, `prj_`, `agt_`, `mch_`, `ses_`, `cnv_`, `msg_`, `inv_`.
- [ ] Branded TypeScript types so a `ProjectId` cannot be passed where an `AgentId` is expected.
- [ ] A frozen error-code enum plus the `{ error: { code, message } }` envelope schema.
- [ ] `PROTOCOL_VERSION` and `MIN_CLIENT_VERSION` constants are exported.
- [ ] Zod is the only runtime dependency.
- [ ] Unit tests cover ID round-trips and rejection of wrong prefixes.
