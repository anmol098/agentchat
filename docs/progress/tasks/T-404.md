# T-404 — Harness integration examples

Copy-paste instructions that get a coding agent listening inside each major harness, which is where adoption actually happens.

## Acceptance criteria

- [ ] Working examples exist for at least Claude Code and Codex, showing how to keep a listener alive and consume its output.
- [ ] Each example is a file a user can drop into their repository with minimal edit.
- [ ] Examples explain that the agent decides what a message means, with no semantic schema implied.
- [ ] A shell example shows consuming `listen --json` without any harness at all.
- [ ] Every example is tested manually and the result recorded in the task log.
