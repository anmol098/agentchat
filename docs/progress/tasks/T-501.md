# T-501 — Production container image

The artefact both the reference deployment and every self-hoster runs, built once and promoted rather than rebuilt per environment.

## Acceptance criteria

- [ ] A multi-stage build produces a minimal runtime image that does not contain build tooling or source.
- [ ] The image runs as a non-root user.
- [ ] Migrations are bundled in the image so upgrading needs no repository checkout.
- [ ] The image builds for both amd64 and arm64.
- [ ] An entrypoint supports both serving and a `migrate` subcommand.
- [ ] A built image passes the health check when pointed at a Postgres.
