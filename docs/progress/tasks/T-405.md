# T-405 — Protocol reference documentation

The document an independent implementer would need to write a compatible client without reading the server source.

## Acceptance criteria

- [ ] Every HTTP endpoint is documented with its request, response, and error codes.
- [ ] Every WebSocket frame in both directions is documented with an example.
- [ ] Delivery semantics, acknowledgement, and replay are described precisely enough to reimplement.
- [ ] The additive-only compatibility rule and version negotiation are stated.
- [ ] The document is generated from or verified against the protocol schemas so it cannot silently drift.
