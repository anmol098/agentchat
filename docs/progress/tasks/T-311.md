# T-311 — Send command

The sending half of the user-facing product, including reading a message body from standard input so an agent can pipe generated text.

## Acceptance criteria

- [ ] `agentchat send @user/agent "text"` resolves project and sender agent from context.
- [ ] A body of `-` reads the message from standard input.
- [ ] `--conversation` and `--reply-to` are supported, and reply-to inherits the parent conversation.
- [ ] A generated client message identifier makes a retried send safe.
- [ ] Unknown recipients produce a message naming the discovery command rather than a raw error.
- [ ] Tests cover argument form, standard input form, and threading.
