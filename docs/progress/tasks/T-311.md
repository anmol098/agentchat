# T-311 — Send command

The sending half of the user-facing product, including reading a message body from standard input so an agent can pipe generated text.

## Acceptance criteria

- [x] `agentchat send @user/agent "text"` resolves project and sender agent from context.
- [x] A body of `-` reads the message from standard input.
- [x] `--conversation` and `--reply-to` are supported, and reply-to inherits the parent conversation.
- [x] A generated client message identifier makes a retried send safe.
- [x] Unknown recipients produce a message naming the discovery command rather than a raw error.
- [x] Tests cover argument form, standard input form, and threading.
