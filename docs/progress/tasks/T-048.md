# T-048 — A dedicated close code for a socket closed for not reading

T-032 closes a socket whose peer has stopped reading, and closes it with `1000`. That is defensible: `1000`'s documented remedy is reconnect and take the replay, which is exactly right here, and the cause travels in the close frame's reason.

It is still the wrong code for one reader. A client collecting its own metrics cannot separate "the server restarted" from "I stopped reading my socket". Those have opposite fixes — one is somebody else's deploy, the other is a bug in the client's own event loop — and a reason string is prose, not a key.

T-032 did not mint one, correctly. `CloseCode` lives in `server/src/websocket/frames.ts`, outside its declared paths, and section 9 forbids an agent minting a wire code unilaterally.
