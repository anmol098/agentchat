# T-108 — Invite routes and service

Invite-based joining: any member may mint a code, anyone may preview it before committing, and joining is idempotent.

## Acceptance criteria

- [ ] Codes use the documented human-readable format and are generated from a cryptographically secure source.
- [ ] Any project member may create an invite; the default expiry is seven days with unlimited uses.
- [ ] Previewing a code returns the project name and inviter without requiring membership, and reveals nothing else.
- [ ] Joining is idempotent, and expired or revoked codes fail with distinct error codes.
- [ ] Integration tests cover preview, join, re-join, expiry, and revocation.
