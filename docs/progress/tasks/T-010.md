# T-010 — Typecheck root configuration and cross-cutting tests

`pnpm typecheck` fans out to workspace members, so nothing at the repository root is checked at all. `vitest.config.ts`, `tests/`, and `scripts/` are invisible to the compiler.

This is not theoretical. T-003 set `coverage.all`, an option Vitest 5 removed. Vite does not validate configuration objects, so the setting was silently ignored at runtime and surfaced only when that task ran the compiler manually against a throwaway configuration. A root project would have caught it, and the next such mistake will not have someone checking by hand.

## Acceptance criteria

- [ ] A root TypeScript project covers `vitest.config.ts` and `tests/`, and `pnpm typecheck` includes it.
- [ ] The root project extends `tsconfig.base.json` and weakens none of its settings.
- [ ] Deliberately introducing a type error in the root configuration fails `pnpm typecheck`.
- [ ] Workspace member type-checking is unaffected and still runs.
- [ ] Reintroducing a removed Vitest option is caught by the compiler.
