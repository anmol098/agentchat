# T-309 — WebSocket heartbeat and stale connection close

Detects dead connections so presence stays honest and sockets do not accumulate.

## Acceptance criteria

- [ ] The server pings every twenty seconds and closes a socket with no response for sixty.
- [ ] Closing a socket marks its session stale and updates the last-seen timestamp.
- [ ] Client pings are answered with a pong.
- [ ] Timers are cleared on close so the process can exit.
- [ ] Tests cover a responsive client and a silent one.
