# T-007 — Fastify server bootstrap and health endpoint

A server that boots, validates its configuration, logs in structured JSON, and answers a health check that actually verifies the database.

## Acceptance criteria

- [ ] Configuration is parsed and validated with zod at startup; a missing required variable fails fast with a readable message.
- [ ] `GET /healthz` returns 200 with a database round-trip, and 503 when the database is unreachable.
- [ ] Structured pino logging to stdout with request IDs.
- [ ] Graceful shutdown on SIGTERM closes the HTTP server and the database pool.
- [ ] An integration test covers both healthz outcomes.

## Notes
