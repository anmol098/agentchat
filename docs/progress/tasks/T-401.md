# T-401 — Presence and agent discovery endpoint

Lets an agent find out who else is in the project and whether they are reachable right now.

## Acceptance criteria

- [x] The endpoint returns each project agent with its owner, online state, and active session count.
- [x] Online means at least one active session in that project.
- [x] Soft-deleted agents are excluded.
- [ ] Runtime metadata is included but clearly secondary to the agent identity. **Not met.** Split out as T-034; it needs three files across two packages that this task did not own.
- [x] The query is a single round trip, not one per agent.
- [x] Integration tests cover online and offline states.

## Notes

Plan section 3, PRD section 21, section 43, section 44. Runtime is metadata and must never read as identity.
