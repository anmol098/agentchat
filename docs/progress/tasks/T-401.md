# T-401 — Presence and agent discovery endpoint

Lets an agent find out who else is in the project and whether they are reachable right now.

## Acceptance criteria

- [ ] The endpoint returns each project agent with its owner, online state, and active session count.
- [ ] Online means at least one active session in that project.
- [ ] Soft-deleted agents are excluded.
- [ ] Runtime metadata is included but clearly secondary to the agent identity.
- [ ] The query is a single round trip, not one per agent.
- [ ] Integration tests cover online and offline states.
