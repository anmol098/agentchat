# T-312 — Listen command and the stdout contract

The command that makes an agent reachable. A blocking process that registers a session, prints incoming messages to stdout in a stable format, and acknowledges only once the write has actually landed.

## Acceptance criteria

- [x] `--runtime` is required and a missing value exits 2 with a usage error.
- [x] A session is registered on start and ended on SIGINT or SIGTERM, exiting 0.
- [x] Human output matches the documented format including the ready-made reply command line.
- [x] `--json` emits newline-delimited JSON, one object per event, including connection status events.
- [x] Acknowledgement is sent only after the stdout write completes, and `--no-ack` disables it.
- [x] Nothing but message payloads is ever written to stdout; all operational logging goes to stderr.
- [x] An automated test asserts the stream separation and survives a reconnect.

## Notes

Plan §6.3, PRD §38-40, decision D14. The stream separation test must never be weakened; it is the integration contract.
