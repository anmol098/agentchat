# T-002 — Biome lint and format configuration

Single tool for linting and formatting so no task argues about style. Configuration is strict enough to catch real defects, not just cosmetics.

## Acceptance criteria

- [ ] `pnpm lint` and `pnpm format:check` run across every workspace package.
- [ ] Rules ban `any`, unused exports, floating promises, and non-null assertions.
- [ ] `.editorconfig` matches the formatter so editors do not fight it.
- [ ] Running `pnpm format` on the repository produces no diff afterwards.

## Notes

Protocol §7.1. These commands are the pull-request gate, so they must be fast and deterministic.
