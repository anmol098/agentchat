# T-503 — Version endpoint and compatibility negotiation

Makes client and server version mismatch a clear instruction rather than a confusing failure, which matters once strangers run their own servers.

## Acceptance criteria

- [ ] An unauthenticated version endpoint returns the server version, protocol version, and minimum client version.
- [ ] A client older than the minimum receives 426 with a stable code, and the CLI prints the exact upgrade command.
- [ ] A client newer than the server prints a single stderr warning and continues.
- [ ] The client version header is sent on every request and in the hello frame.
- [ ] Tests cover too-old, too-new, and matched versions.
