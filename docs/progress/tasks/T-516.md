# T-516 — Release 0.3.0, so the skill and its auto-install ship

T-512 through T-515 are on `main` and in no release: `skills/agentchat/`, its
discoverability via skills.sh (badge, install instructions), and the
`postinstall` script that installs it automatically on
`npm install --global @anmol098/agentchat`. None of it is reachable by a real
user until it ships.

This is a **minor**, not a patch: new, backward-compatible capability (the
Skill and the auto-install behaviour), not a bug fix. Nothing in it touches
the wire protocol or the schema — `PROTOCOL_VERSION` stays `5` and
`MIN_CLIENT_VERSION` stays `0.1.0`, exactly as for T-073's patch release,
because an old client and a new server (or the reverse) still agree on
everything the wire actually carries.
