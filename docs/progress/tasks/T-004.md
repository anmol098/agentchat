# T-004 — Continuous integration workflow

The gate that enforces the quality standard. Runs format, lint, typecheck, unit tests, and integration tests against a Postgres service container on every push and pull request.

## Acceptance criteria

- [ ] Workflow runs `format:check`, `lint`, `typecheck`, `test`, and `test:integration`.
- [ ] A Postgres service container is available to the integration job with `DATABASE_URL` wired in.
- [ ] pnpm store is cached between runs.
- [ ] The workflow is required for merging into `main`.
- [ ] A deliberately broken commit fails the workflow.

## Notes

Protocol section 7.1. Keep the job names stable; branch protection references them.
