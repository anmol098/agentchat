# T-206 — Authentication commands

Login, logout, and whoami. Login drives the device flow with clear instructions and a bounded poll.

## Acceptance criteria

- [ ] `agentchat login` prints the verification URL and user code, then polls at the interval the server specifies.
- [ ] Polling honours the slow-down signal and stops at expiry with a helpful message.
- [ ] `agentchat logout` revokes the refresh token server-side and removes local credentials.
- [ ] `agentchat whoami` reports the user and configured server, and exits 3 when logged out.
- [ ] Tests cover the pending, success, denied, and expiry paths.
