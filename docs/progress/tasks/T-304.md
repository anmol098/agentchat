# T-304 — Inbox and agent-scoped acknowledgement

The pending-message queue and the acknowledgement rule that makes replay correct when one agent runs several sessions.

## Acceptance criteria

- [ ] Pending messages are listed per agent and project in chronological order with a documented limit.
- [ ] An acknowledgement from any session of the agent clears the message for that agent.
- [ ] Acknowledgement is idempotent; a repeat is a no-op, not an error.
- [ ] Acknowledging a message addressed to a different agent is refused.
- [ ] The per-session delivery record is updated for diagnostics without affecting the pending state.
- [ ] Integration tests cover multi-session acknowledgement and repeated acknowledgement.
