# T-303 — Message service with idempotent send

Accepting a message: authorization, size validation, conversation resolution, and idempotency, all committed before any delivery is attempted.

## Acceptance criteria

- [ ] Sender must be owned by the caller and participate in the project; recipient must participate in the same project.
- [ ] Content over 1 MiB is rejected with a distinct error code.
- [ ] Sending without a conversation creates one; `--reply-to` inherits the parent conversation.
- [ ] A repeated `client_message_id` from the same sender returns the original message rather than creating a second one.
- [ ] The message row and its inbox row are committed in one transaction before delivery is attempted.
- [ ] Integration tests cover cross-project rejection, oversize rejection, and duplicate send.
