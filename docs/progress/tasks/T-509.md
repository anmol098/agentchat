# T-509 — Resilience and failure-mode tests

Deliberate abuse of the delivery path, because at-least-once delivery is only worth claiming if it has been tested under failure.

## Acceptance criteria

- [ ] A socket dropped mid-delivery results in redelivery, not a lost message.
- [ ] A server restart with pending inbox rows delivers them once listeners reconnect.
- [ ] Duplicate acknowledgements and out-of-order acknowledgements are harmless.
- [ ] An access token expiring during a long-lived listen is refreshed without dropping a message.
- [ ] A message at the size limit succeeds and one over it is refused cleanly.
- [ ] A slow consumer does not stall delivery to other sessions.
