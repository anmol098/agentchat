# T-504 — Deployment stack with automatic TLS

The reference deployment, which is also exactly what a self-hoster runs: a single virtual machine with the server, Postgres, and a reverse proxy handling certificates.

## Acceptance criteria

- [x] A Compose stack runs the reverse proxy, server, and Postgres with a persistent volume.
- [x] TLS certificates are obtained and renewed automatically.
- [x] The image version is pinned by an environment variable and never defaults to a floating tag.
- [x] WebSocket upgrades pass through the proxy with no timeout shorter than the application heartbeat.
- [x] An example environment file documents every variable, and secrets are never committed.
- [x] A systemd unit starts the stack on boot.
- [x] A clean virtual machine reaches a working server by following the documented steps only.

## Notes

Plan §8 M5, §12.5, decision D6. A dedicated instance was chosen over a serverless platform precisely to avoid a request timeout capping WebSocket lifetime.
