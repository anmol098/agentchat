# T-008 — Board validation in continuous integration

Keeps the progress board trustworthy by failing the build when a task file is malformed, a dependency is unknown, two active tasks own overlapping paths, or the rendered board is stale.

## Acceptance criteria

- [ ] `node scripts/board.mjs check` runs on every pull request.
- [ ] A stale `BOARD.md` fails the check.
- [ ] The failure message tells the contributor exactly which command to run.

## Notes

Protocol §1. The board is derived state; this job is what stops it drifting.
